ThaiTan 개인정보처리방침

시행일: 2026년 6월 9일 | 최종 수정: 2026년 6월 10일

ThaiTan(이하 "타이탄")은 사용자의 개인정보를 소중히 여기며, 관련 법률 및 Google Chrome 웹스토어 개발자 프로그램 정책을 준수합니다. 본 개인정보처리방침은 타이탄 크롬 익스텐션이 수집하는 데이터의 유형, 목적, 보관 및 보호 방법을 설명합니다.

1. 수집하는 정보

데이터 유형 내용 수집 목적
익명 사용자 식별자 (UUID) 확장 프로그램 설치 시 무작위 생성되는 고유 문자열 익명 사용 통계 집계
방문 페이지 URL 및 제목 사용자가 익스텐션을 실행한 웹페이지의 주소와 제목 사용 통계 및 분절 로그
웹페이지 텍스트 콘텐츠 분절 대상 태국어 기사 본문 텍스트 문장 분절 처리 (핵심 기능)
기능 사용 이벤트 버튼 클릭, 뷰 전환, 폰트 크기 변경 등의 UI 상호작용 서비스 개선을 위한 익명 사용 패턴 분석
사용자 설정 글꼴 크기 등 UI 환경 설정값 사용자 편의 (로컬 저장)

2. 수집하지 않는 정보

타이탄은 다음 정보를 수집하지 않습니다:

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 로그인 자격 증명 또는 비밀번호
  • 금융·결제 정보
  • 건강 정보
  • 위치 정보
  • 키 입력(키로깅), 스크롤, 마우스 위치 추적
  • 사용자가 익스텐션을 실행하지 않은 페이지의 데이터

3. 데이터 사용 목적

  • 핵심 기능 제공: 태국어 텍스트를 서버로 전송하여 문장 분절 결과를 반환받습니다.
  • 서비스 품질 개선: 익명화된 사용 통계를 Google Analytics 4를 통해 분석하여, 가장 많이 사용되는 기능과 개선이 필요한 부분을 파악합니다.
  • 사용자 경험 유지: 글꼴 크기 등 사용자 설정을 로컬에 저장하여 재방문 시 동일한 환경을 제공합니다.

4. 데이터 공유 및 제3자 제공

타이탄은 수집한 데이터를 제3자에게 판매하지 않으며, 다음의 경우에만 외부로 전송됩니다:

  • 자체 API 서버 (edu.dodream.asia): 문장 분절 처리를 위해 태국어 텍스트가 전송됩니다.
  • Google Analytics 4: 익명 사용 이벤트가 Google의 Measurement Protocol을 통해 전송됩니다. 개인 식별 정보는 포함되지 않습니다.

5. 데이터 보관 및 삭제

  • 로컬 데이터 (UUID, 설정값): 사용자 기기의 chrome.storage.local에 저장되며, 익스텐션을 삭제하면 자동으로 제거됩니다.
  • 서버 로그: 분절 요청 로그는 서비스 운영 목적으로 서버에 보관되며, 개인 식별이 불가능한 익명 데이터입니다.
  • GA4 데이터: Google의 데이터 보존 정책(기본 14개월)에 따릅니다.

6. 데이터 보안

타이탄은 전송 중인 데이터를 HTTPS 암호화 프로토콜로 보호합니다. API 서버에는 기본 인증 및 요청 빈도 제한(Rate Limiting)을 적용하여 서버 남용을 방지합니다.

7. 사용자의 권리

  • 익스텐션을 삭제하면 기기에 저장된 모든 로컬 데이터가 즉시 삭제됩니다.
  • 서버에 저장된 익명 로그 데이터의 삭제를 요청할 수 있습니다.
  • 데이터 관련 문의는 아래 연락처로 보내주세요.

본 방침은 서비스 변경에 따라 수정될 수 있으며, 변경 시 본 페이지에 업데이트됩니다. 중요한 변경 사항은 익스텐션 업데이트 노트를 통해 안내됩니다.

ThaiTan Privacy Policy

Effective Date: June 9, 2026 | Last Updated: June 10, 2026

ThaiTan ("we", "our", or "the extension") values your privacy and complies with applicable laws and the Google Chrome Web Store Developer Program Policies. This Privacy Policy explains what data ThaiTan collects, how it is used, and how it is protected.

1. Information We Collect

Data Type Details Purpose
Anonymous User ID (UUID) A randomly generated unique string created upon installation Anonymous usage statistics
Page URL & Title The URL and title of the webpage where the extension is activated Usage statistics and analysis logs
Webpage Text Content Thai article body text from the active page Sentence segmentation (core functionality)
Feature Usage Events Button clicks, view toggles, font size changes, and other UI interactions Anonymous usage pattern analysis for service improvement
User Preferences Font size and other UI settings User convenience (stored locally)

2. Information We Do NOT Collect

  • Personally identifiable information (name, email, phone number)
  • Login credentials or passwords
  • Financial or payment information
  • Health information
  • Location data
  • Keystrokes, scroll positions, or mouse movement tracking
  • Data from pages where the extension is not actively used

3. How We Use Your Data

  • Core Functionality: Thai text is sent to our server for sentence segmentation processing.
  • Service Improvement: Anonymous usage statistics are analyzed via Google Analytics 4 to identify popular features and areas for improvement.
  • User Experience: Preferences such as font size are stored locally to maintain consistent settings across sessions.

4. Data Sharing & Third Parties

We do not sell any collected data. Data is only transmitted to:

  • Our API Server (edu.dodream.asia): For Thai text segmentation processing.
  • Google Analytics 4: Anonymous usage events are sent via the Measurement Protocol. No personally identifiable information is included.

5. Data Retention & Deletion

  • Local Data: Stored in chrome.storage.local and automatically removed when the extension is uninstalled.
  • Server Logs: Analysis request logs are retained for operational purposes and contain only anonymous data.
  • GA4 Data: Subject to Google's data retention policy (default 14 months).

6. Data Security

All data in transit is protected via HTTPS encryption. The API server applies basic authentication and rate limiting to prevent unauthorized or excessive use.

7. Your Rights

  • Uninstalling the extension immediately deletes all locally stored data.
  • You may request deletion of anonymous server logs.
  • For any data-related inquiries, please contact us using the information below.
